# Assets

Ce dossier doit contenir les fichiers suivants :

## Images requises

- `icon.png` - Icône de l'app (1024x1024 px, carré obligatoire)
- `splash.png` - Écran de démarrage (1284x2778 px recommandé)
- `adaptive-icon.png` - Icône adaptive Android (1024x1024 px, carré obligatoire)

⚠️ **Important pour Expo 54** : Les icônes doivent être parfaitement carrées (même largeur et hauteur).

## Sons (optionnel)

Le dossier `sounds/` peut contenir des fichiers audio d'adhan locaux :

- `adhan-makkah.mp3`
- `adhan-madinah.mp3`
- `adhan-alaqsa.mp3`
- `adhan-mishary.mp3`
- `adhan-egypt.mp3`

## Créer les assets rapidement

Vous pouvez utiliser un générateur d'icônes comme :
- https://icon.kitchen/
- https://appicon.co/

Suggestion : fond vert émeraude (#10b981) avec un croissant ou mosquée blanc.
